AfA Dashboard — User Guide

An interactive companion to the official User Guide, with a live, in-browser simulator you can try without installing anything.

About this page This is a companion to the official User Guide (Product 3), produced as a Word document for formal submission. The content is the same; this version adds a live simulator so you can see how the model responds before installing the dashboard itself.

1. What this guide is for

This guide explains how to use the AfA Dashboard: a tool for exploring how an infectious disease, such as COVID-19, might spread under different conditions, and what that could mean for hospitals and health systems.

You do not need a background in statistics, epidemiology, or computer programming to use this guide or the dashboard itself. Every screen, button, and chart is explained in plain language.

How this guide works The main text explains everything you need to use the dashboard with confidence. Throughout the guide, you will also find boxes like this one, titled "For more detail". These are entirely optional — they explain a little more about how something is calculated, for readers who want to understand the method behind a number. You can skip them completely and still get full value from the dashboard.

This guide covers:

  • How to open the dashboard and load a dataset.
  • How to use the Advanced View, which gives you full control over every parameter of the model, including how to download your results.
  • How to use the Simple View, a streamlined view built around three key indicators and a small number of controls.
  • Answers to common questions about interpreting what you see.
Note If you need to install or publish the dashboard rather than simply use it, see the Implementation Guide instead.

2. Getting started

When you open the dashboard, you will see an entry screen with a single card in the centre. This is where you choose what data the dashboard should use, before moving on to explore it.

2.1 Choosing a dataset source

Under "Dataset source", you can choose between two options:

OptionWhat it does
Simulated (mock)Loads a ready-made example dataset, built from typical default values. This is the quickest way to explore the dashboard — you do not need to prepare anything in advance.
Upload your own dataset (CSV)Lets you load your own set of epidemiological and health-system values, specific to the country, region, or scenario you want to study.

Once you have chosen an option, click the "Load dataset" button. A short message will appear confirming that the dataset loaded successfully.

2.2 Uploading your own dataset

If you choose to upload your own dataset, you will need a CSV file — a simple spreadsheet format that most spreadsheet programs (such as Excel or Google Sheets) can create by using "Save As" or "Export" and choosing the CSV format.

Your file must have exactly two columns, named parameter and value, and must include the following ten rows:

Row name ("parameter")What it represents
r0How many people, on average, one infected person passes the disease to.
incubation_periodThe average number of days between catching the disease and starting to show symptoms.
infectious_periodThe average number of days during which an infected person can pass on the disease.
ifrThe infection fatality rate: the proportion of infected people who are expected to die, as a result of the disease.
icu_capacityThe total number of intensive care unit (ICU) beds available.
ventilator_availabilityThe total number of ventilators (breathing-support machines) available.
healthcare_staffThe total number of healthcare staff available to treat patients.
icu_admission_rateThe proportion of infected people expected to need an ICU bed.
ventilator_usage_rateThe proportion of infected people expected to need a ventilator.
populationThe total population of the area you are studying.
Tip Argentina reference defaults are shown in the upload window as a guide. You do not need to use these exact figures — replace them with values appropriate to your own country, region, or scenario.
If your file does not load The dashboard checks your file before using it. If a row is missing, misspelled, or contains a value that is not a number, you will see a message explaining exactly what needs fixing. Correct your file and try uploading it again.

2.3 Choosing a view

After loading a dataset, choose between two ways of exploring it:

  • Advanced View — gives you full control over every parameter of the model, with detailed charts. Best if you want to explore specific scenarios in depth.
  • Simple View — a streamlined view built around three key indicators and two main controls. Best for a quick read of how a scenario is developing.

Both views start from the same dataset. From that point on, they work independently — a change you make in one view has no effect on the other. This means you can use both views side by side to compare a detailed exploration against a quick summary.

3. The Advanced View

The Advanced View gives you full control over the model behind the dashboard. It is organised into a parameter panel, on the left or top of the screen depending on your device, and a set of charts that update once you run a simulation.

3.1 Setting your parameters

The parameter panel lets you adjust every input the model uses. These are grouped as follows:

Parameter groupWhat it controls
Disease parametersHow infectious the disease is, how long it takes to show symptoms, how long someone remains infectious, and how likely an infected person is to die from it.
Policy and complianceWhich type of public health response is in place (for example, gradual restrictions or on-off interventions), and how closely the population follows it.
Healthcare resourcesHow many ICU beds, ventilators, and healthcare staff are available, and what proportion of infected people are expected to need each of these.
Simulation scopeThe start and end dates of the period you want to simulate.
For more detail The "Policy and compliance" setting changes how strongly the model reduces transmission. Under the "Phased Mitigation" policy, for example, full compliance with the measures in place reduces the effective spread of the disease by up to half compared with no measures at all.

Once you are happy with your settings, click the button to run the simulation. The charts on the right (or below, on smaller screens) will update to reflect your chosen scenario.

3.2 Reading the charts

The Advanced View includes several charts. Each one tells a different part of the story:

ChartWhat it shows
SEIR curvesHow the population moves between four groups over time: people who can still catch the disease, people who have caught it but cannot yet pass it on, people who can currently pass it on, and people who have recovered (or are no longer infectious).
Cumulative cases and deathsThe running total of cases and deaths over the simulated period, rather than the daily figures.
Healthcare resource pressureHow the demand for ICU beds and ventilators compares with the capacity you specified, over time. Where demand crosses the capacity line, the health system would be under strain.

Hover your mouse over any point on a chart to see the exact values for that day.

3.3 Exporting your results

Click the download button above the charts to export the full set of simulation results as a CSV file, which you can open in any spreadsheet program for further analysis, reporting, or sharing with colleagues. This file contains the day-by-day values behind everything shown in the charts.

Tip The file uses the European number format (for example, 1.234,56 rather than 1,234.56). You may need to adjust your spreadsheet program's regional settings if the numbers do not display correctly when you open it.
Note This export is only available in the Advanced View. The Simple View does not include a download option, as it is designed for a quick read of the indicator cards rather than detailed analysis.

4. The Simple View

The Simple View is designed for a quick read of how a scenario is developing, without needing to interpret detailed charts. It is built around three indicator cards and a small number of controls.

4.1 The three indicator cards

CardWhat it tells you
Epidemic TrajectoryWhether the number of currently infectious people is rising or falling, by comparing the most recent week of the simulation with the week before it.
ICU PressureHow much of your intensive care capacity is in use by the end of the simulated period, as a percentage.
Cumulative DeathsThe total number of deaths by the end of the simulated period, as a percentage of the population.

Each card is colour-coded, using the same three states throughout the dashboard:

Controlled — comfortably below its warning level. No cause for concern under the current scenario.
Warning — past its warning level, but not yet critical. Worth keeping an eye on.
Critical — past its critical level. A serious situation under the current scenario.
For more detail ICU Pressure is based on how many ICU beds are in use on the final day of the simulation, accounting for an average hospital stay of ten days, rather than on the single worst day of the simulation. This is a deliberate design choice: under fast-spreading scenarios, the worst single day can be many times higher than total capacity, which produces a number that is technically correct but not useful for decision-making. The final-day figure gives a more stable, comparable read of pressure on the health system.

4.2 The scenario controls

Below the three cards, two sliders let you adjust the scenario directly:

ControlWhat it does
R₀ — Basic Reproduction NumberHow many people, on average, one infected person passes the disease to. Higher values mean faster spread.
Compliance Level (%)How closely the population is following prevention measures, such as distancing or mask-wearing. At 0%, no measures are reducing spread. At 100%, the disease's effective spread is reduced by half.

Unlike the Advanced View, changing either of these sliders re-runs the simulation immediately — there is no separate button to click. The three cards update straight away to reflect your new scenario.

4.3 Adjusting the alarm thresholds

By default, each card uses standard warning and critical levels. If these do not match your own context, click "Settings — Alarm Thresholds" to reveal six fields, two for each card:

CardDefault warning levelDefault critical level
Epidemic Trajectory1% weekly growth20% weekly growth
ICU Pressure70% of capacity100% of capacity
Cumulative Deaths0.05% of population0.20% of population
Note Changing these thresholds only changes when a card turns orange or red — it does not change the simulation itself, and does not require you to run it again. This makes it quick to test "what would concern me" without affecting your scenario.

For more detail: how this simulator calculates its results The simulator solves the same four SEIR equations as the dashboard (dS, dE, dI, dR), using the same default parameters for Argentina (population 45,000,000; incubation period 5 days; infectious period 7 days; infection fatality rate 1%; ICU admission rate 13.6%; ICU capacity 6,000 beds; average hospital stay 10 days), over a 365-day period. The effective reproduction number is calculated as R₀ × (1 − Compliance × 0.5), exactly as in the dashboard's Advanced and Simple Views. A simple fixed-step numerical method (RK4) is used to solve the equations in JavaScript, in place of the deSolve package used in R.

5. Frequently asked questions

Why does my ICU Pressure figure look much higher than 100%?

Under fast-spreading scenarios, demand for ICU beds can genuinely exceed available capacity many times over. A figure such as 300% or higher is not an error — it reflects a scenario in which demand for intensive care has substantially outstripped what is available. See Section 4.1 for more on how this figure is calculated.

What is the difference between the Advanced View and the Simple View?

The Advanced View gives you full control over every model parameter and shows detailed charts — better suited to in-depth exploration. The Simple View focuses on three key indicators and two main controls, for a faster read of a scenario. Both use the same underlying model and the same starting dataset, but they run independently once loaded: changes in one do not affect the other.

Can I trust the default values shown when I upload my own dataset?

The default values shown as a guide are based on published epidemiological research for Argentina. They are a reasonable starting point, but you should replace them with figures that reflect your own country, region, or scenario wherever these are available.

Why do the two views show different results for what looks like the same scenario?

The two views are intentionally kept separate once a dataset is loaded. If you change a slider in the Advanced View, this has no effect on the Simple View, and vice versa. To compare like with like, set the same values in both views.

My uploaded file was rejected. What should I check first?

Confirm that your file has exactly two columns named parameter and value, that all ten required rows are present and correctly spelled (see Section 2.2), and that every value is a plain number, with no text, currency symbols, or thousands separators.
